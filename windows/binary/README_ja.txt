Rogue 3.6 JEC  Windows版
=======================

Rogueは1980年頃に誕生した、文字や記号で描かれる迷宮を探索する
コンピューターRPGです。プレイヤーは怪物と戦い、さまざまな道具を
使いながら、迷宮の奥に隠された「イェンダーの魔除け」を探します。
いわゆる「ローグライクゲーム」の元祖です。

Rogue 3.6は現在入手できる最古のRogueのバージョンであり、Rogueの
原点とも言えるものです。最終版の5.4とは異なる怪物、道具、ゲームの
仕組みなど、初期のRogueならではの特徴が残されています。

このパッケージは、Windows 10 / 11（64ビット）向けのRogue 3.6 JECです。
元のRogue 3.6のゲーム内容をできるだけ尊重し、日本語・英語の
切り替え、日本語や絵文字の入出力、現代のWindowsへの対応、
表示やセーブ処理の改善などを加えています。

「はじまりのRogue」をお楽しみください。

【同梱ファイル】

  rogue36.exe       ゲーム本体
  rogue_ja.html     【運命の洞窟】への案内書（日本語版）

  README_en.txt     英語のREADME

【起動方法】

1. ZIPファイルを任意のフォルダーに展開してください。

2. エクスプローラーから起動する場合は、rogue36.exeを
   ダブルクリックしてください。

   標準のセーブファイル（rogue36.save）が見つかった場合にだけ、
   次の起動メニューが表示されます。

     [R/Enter] セーブした冒険を再開する
     [N]       新しい冒険を始める
     [F]       別のセーブファイルを選ぶ
     [Q]       終了する

   標準のセーブファイルがなければ、メニューなしで新しい冒険が始まります。
   [F]ではWindowsのファイル選択画面が開き、キャンセルすると
   メニューに戻ります。[N]を選んでも既存のセーブファイルは
   削除されません。再開に失敗した場合はエラーを表示し、
   Enterを押すまでウィンドウを保持します。

3. セーブファイルをrogue36.exeのアイコンにドラッグ＆ドロップすると、
   そのファイルから直接再開できます。日本語を含むフォルダー名や
   ファイル名にも対応しています。

4. ターミナルから起動する場合は、展開先フォルダーを開いてください。
   Windows 11では右クリックの「ターミナルで開く」を使用できます。
   その項目がない場合は、エクスプローラーのアドレスバーに
   powershellと入力してEnterを押してください。

       .\rogue36.exe

   コマンドプロンプト（cmd.exe）からも起動できます。
   既に開いているターミナルから引数なしで起動した場合は、
   起動メニューを表示せずに新しいゲームが始まります。

ゲームの画面は80列×24行に固定されています。端末も80列×24行以上で
ご利用ください。ダブルクリック起動時には、Windows Terminalまたは
Console Hostのウィンドウを80×24に調整する処理が働きますが、
表示環境によっては調整できない場合があります。既存のターミナルから
起動した場合は、ウィンドウサイズを変更しません。

ダブルクリック起動では、ゲーム終了後に画面を消去してスコアを表示し、
Enterを押すまでウィンドウを保持します。既存のターミナルから
起動した場合は、終了時の入力待ちは行いません。


【セーブデータとスコア】

既定のファイル名は次のとおりです。

  セーブファイル    rogue36.save
  スコアファイル    rogue36.scr
  ロックファイル    rogue36.lock

これらは通常、起動時の作業フォルダーに作成されます。
エクスプローラーから直接起動した場合は、通常、実行ファイルがある
フォルダーです。上記はrogue36という名前でビルドした場合の既定値で、
実行ファイルの名前を後から変更しても連動して変わるわけではありません。

ターミナルから既定のセーブファイルを再開する場合：

       .\rogue36.exe rogue36.save

別の名前や場所のセーブファイルを指定する場合：

       .\rogue36.exe "C:\Games\Rogue36\my-save.save"

スコア一覧だけを表示する場合：

       .\rogue36.exe -s

正常に再開したセーブファイルは自動で削除されます。
残しておきたい場合は、再開前にコピーしてください。
ROGUEOPTSでfile=を指定した場合は、その設定が既定の保存先に優先します。

このバイナリ配布版は、Windowsの「保存したゲーム」フォルダーへの
自動保存には設定されていません。ソースから個人用にビルドする場合は
「FILEDIR=saved-games」を指定できますが、作成したEXEにその
ユーザーの保存先が組み込まれるため、配布には適しません。

【Windowsでの環境変数の設定】

起動時の設定には環境変数ROGUEOPTSを使用できます。
表示言語はlanguage=ja（日本語）またはlanguage=en（英語）で指定します。
その他のオプションの意味は、同梱の日本語版案内書の
「9. オプション」をご覧ください。
ここではWindowsでの設定方法を説明します。

PowerShellで一時的に設定する例：

       $env:ROGUEOPTS = "name=勇者,language=ja"
       .\rogue36.exe

コマンドプロンプト（cmd.exe）での例：

       set "ROGUEOPTS=name=勇者,language=ja"
       rogue36.exe

これらの設定は、そのターミナルとそこから起動するプログラムに
適用されます。別途エクスプローラーからダブルクリックした場合には
引き継がれません。

ダブルクリック起動にも適用する場合は、Windowsのユーザー環境変数に
ROGUEOPTSを登録してください。

  1. Win + Rで「ファイル名を指定して実行」を開き、sysdm.cplを実行。
  2. 「詳細設定」→「環境変数」を開く。
  3. 「ユーザー環境変数」で「新規」を選ぶ（既存なら「編集」）。
  4. 変数名をROGUEOPTSとし、変数値に設定文字列を入力する。
  5. 「OK」で保存する。反映されない場合はWindowsに再サインインする。
