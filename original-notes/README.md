# Original Rogue 3.6 auxiliary files / オリジナルRogue 3.6の付属資料

このディレクトリには、オリジナルRogue 3.6に付属していた旧式の補助プログラムと歴史的資料を、内容を変更せずに保存しています。これらはRogue 3.6 JECの通常ビルドでは使用しません。

| ファイル | 内容 |
| --- | --- |
| `findpw.c` | 旧ウィザード用のパスワード補助プログラム |
| `initsfile.c` | 旧式スコアファイルの変換用プログラム |
| `edd` | 旧環境向けの`ed`編集コマンド |
| `listfile` | 元の配布媒体に関するファイル抽出コマンド |
| `mes` | オリジナル3.6の矢の罠に関する修正資料 |

**注意：** これらは参考資料です。特に`initsfile.c`は現行JEC版のスコアファイルに使用しないでください。実行・ビルドは想定していません。

---

This directory preserves historical auxiliary programs and notes shipped with the original Rogue 3.6 source. Their contents are unchanged, and none is used by the standard Rogue 3.6 JEC build.

`findpw.c` is an old wizard-password utility; `initsfile.c` is an obsolete score-file conversion utility; `edd` contains old `ed` commands; `listfile` relates to file extraction from original distribution media; and `mes` documents an arrow-trap fix.

**Note:** These files are retained for reference only. Do not use `initsfile.c` on current JEC score files.
